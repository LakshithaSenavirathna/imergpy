# Security Policy

## Reporting Security Issues

Please do not open public issues for exposed credentials or security-sensitive bugs.

Contact: lakshithasrimal256@gmail.com

## Credential Safety

Do not commit:

- NASA Earthdata usernames or passwords
- PyPI tokens
- `.env` files
- downloaded `.xlsx`, `.nc`, or `.nc4` files

If a credential is accidentally exposed, rotate/change it immediately.
